# NextOne Engineering Website

A modern and responsive corporate website developed for **NextOne Engineering Pvt. Ltd.**, showcasing the company's engineering solutions, products, industries served, projects, and contact information.

🚀 Features

- Responsive and user-friendly design
- Home page with company overview
- About Us section
- Products showcase
- Industries served
- Projects portfolio
- Contact page
- Easy navigation and clean UI
- Built using Python Flask framework

🛠️ Tech Stack

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Jinja2 Templates
